# spec.md — CAメンバー追加（福田・清野）

**Agent 1: ProductOwner**
作成日: 2026-06-22 / 起票者: 中川拓哉

## 背景
CAチームに福田・清野の2名が加わったため、週次KPIダッシュボードで2名分の実績・目標・カルテを管理できるようにする。

## ユーザーストーリー
- As a CA管理者（中村）, I want 福田・清野をCAメンバーとして追加, So that 6名分の週次KPIを一元管理できる。
- As a CA（福田／清野）, I want 自分のアカウントでログイン, So that 自分のKPI実績を入力・確認できる。

## 受け入れ条件（Given/When/Then）
- AC-1: Given ログイン画面, When 表示, Then 中村（管理者）・大城・小谷・喜多・福田・清野の6名が選択できる。
- AC-2: Given 福田（または清野）でログイン, When 全体KPI/CS・CSL別タブを開く, Then 自分の行が存在し、自分の行のみ編集できる。
- AC-3: Given 管理者でログイン, When 目標設定タブを開く, Then 福田・清野を含む6名分の目標を設定できる。
- AC-4: Given CAカルテ／同席FBタブ, When 開く, Then 福田・清野が選択肢・担当者として表示される。
- AC-5: Given 既存週（4名時代に保存済み）のデータ, When 読み込む, Then 福田・清野の行が実績0で自動補完され、既存4名のデータは保持される。
- AC-6: Given 保存・読込・Realtime同期, When 6名構成で操作, Then 既存機能が壊れない。

## スコープ外
- 候補者マスタの新設（候補者名は引き続き自由入力）
- 権限モデルの変更（管理者は中村のまま）
- 過去週への遡及入力（必要時に手動）

## 成功指標
- 本番ログイン画面に6名表示
- 6名分のKPI入力→保存→再読込でデータ一致
- ビルド・型エラー0件
